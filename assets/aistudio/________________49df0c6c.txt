⚠️ قواعد صارمة يجب الالتزام بها
═══════════════════════════════════════════════════════════
1. اكتب كود Dart/Flutter كامل 100% لكل ملف بدون أي اختصارات.
2. لا تكتب "..." أو "// TODO" أو "// add code here" — اكتب التنفيذ الفعلي.
3. كل ملف يجب أن يكون قابلاً للنسخ والتشغيل مباشرة.
4. الترتيب: pubspec.yaml → main.dart → app.dart → models → 
   services → providers → widgets → screens.
5. بعد كل ملف اكتب: "✅ انتهى ملف X — قل (كمّل) للملف التالي".
6. استخدم Flutter 3.24+ ومكتبات حديثة مستقرة.
7. الكود يجب أن يـ compile بدون أخطاء.
8. اكتب تعليقات عربية مختصرة فوق الدوال المهمة.

🚨🚨 أهم متطلب في التطبيق (لا تتنازل عنه أبداً) 🚨🚨
═══════════════════════════════════════════════════════════
الإشعارات يجب أن تكون من نوع "Heads-Up / Banner"
أي تظهر فوق الشاشة مثل رسالة SMS أو واتساب تماماً، وليس فقط في 
شريط الإشعارات.

يجب أن:
- تظهر فوق الشاشة فوراً حتى لو المستخدم داخل تطبيق آخر
- تنير الشاشة لو مقفولة (Wake up screen)
- تحتوي على أزرار تفاعلية [تم ✅] [تأجيل ⏰] [فتح]
- تصدر صوت + اهتزاز
- تختفي تلقائياً بعد ثوانٍ أو عند التفاعل

▸ AppLifecycleService — كود كامل:

```dart
class AppLifecycleService with WidgetsBindingObserver {
  final TaskRepository _taskRepo;
  final NotificationService _notif;
  
  AppLifecycleService(this._taskRepo, this._notif) {
    WidgetsBinding.instance.addObserver(this);
  }
  
  @override
  void didChangeAppLifecycleState(AppLifecycleState state) {
    if (state == AppLifecycleState.paused ||
        state == AppLifecycleState.inactive) {
      _notifyIncompleteTasks();
    }
  }
  
  Future<void> _notifyIncompleteTasks() async {
    final incomplete = await _taskRepo.getIncompleteTasksForToday();
    if (incomplete.isNotEmpty) {
      await _notif.showHeadsUpNotification(
        id: 999,
        title: 'لديك ${incomplete.length} مهام لم تكتمل 💪',
        body: 'لا تنسَ إنجاز مهامك اليوم!',
      );
    }
  }
  
  void dispose() => WidgetsBinding.instance.removeObserver(this);
}
```

▸ snoozeTask — كود كامل:

```dart
Future<void> snoozeTask(Task task, Duration duration) async {
  final newTime = DateTime.now().add(duration);
  await _notif.cancelNotification(task.notificationId);
  final updatedTask = task.copyWith(
    dueDate: newTime,
    isSnoozed: true,
    snoozeCount: task.snoozeCount + 1,
  );
  await _notif.scheduleTaskReminder(updatedTask);
  await _taskRepo.updateTask(updatedTask);
  // إظهار SnackBar + HapticFeedback.mediumImpact()
}
```

void _handleNotificationResponse(NotificationResponse response) {
  final taskId = response.payload;
  if (taskId == null) return;
  switch (response.actionId) {
    case 'complete':
      _completeTask(taskId);
      break;
    case 'snooze':
      _snoozeTask(taskId, const Duration(minutes: 15));
      break;
    case 'open':
      _openTaskDetails(taskId);
      break;
  }
}
